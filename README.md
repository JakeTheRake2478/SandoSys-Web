## 📡 Overview

**SandoSys-Web** is the temporary root landing page serving as the placeholder for the upcoming SandoSys core network. 

This repository marks the official and permanent migration of all web dashboards, self-hosted applications, and custom tools from the legacy **NullForge.tech** era to our new, dedicated infrastructure at **SandoSys.com**. 

> `> system_status: standby`
> `> origin_node: nullforge`
> `> destination: sandosys_core`
> `> awaiting_deployment...`

## ✨ Features

While serving as a temporary landing page, this site is built with a focus on clean code and modern UI principles:
* **Glassmorphism UI:** Frosted glass aesthetic built with pure CSS backdrop filters (`blur(16px)`).
* **Ambient Animation:** A subtle, infinitely pulsing radial gradient background to simulate network activity.
* **Zero Dependencies:** 100% vanilla HTML and CSS. No heavy frameworks, no JavaScript—just lightning-fast load times.
* **Fully Responsive:** Fluid layouts that scale perfectly from 4K desktop monitors down to mobile viewports.

## 🚀 The Migration

The transition to SandoSys represents a shift in backend philosophy. Moving away from Firebase-reliant infrastructure, SandoSys is geared toward **complete data sovereignty**. Future deployments routing through this domain will interface with local, self-hosted hardware (Raspberry Pi 5 clusters), local SQLite databases, and strict Role-Based Access Control (RBAC) dashboards.

## 🛠️ Deployment Stack

Currently, this static landing page is deployed using the following pipeline:
1. **Hosting:** GitHub Pages (`jaketherake2478.github.io`)
2. **DNS & Security:** Cloudflare (Strict Full SSL/TLS Encryption, DDoS Protection)
3. **Domain:** Namecheap/Custom Registrar (`sandosys.com`)
